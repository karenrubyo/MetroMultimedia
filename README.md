# MetroMultimedia

Recurso educativo interactivo para aprender los tipos de productos multimedia. Las estaciones de un mapa de metro representan cada producto: sitio web, e-learning, videojuego, realidad aumentada, simulador, podcast, animación, cortometraje y videoclip.

Hecho para la Fase 3 del curso Introducción a la ingeniería (Multimedia), UNAD.

## Cómo usarlo

Abre el enlace y elige entre dos modos:

- **Iniciar viaje:** cinco misiones. Encuentras la estación correcta, respondes una pregunta y desbloqueas un módulo. Cada acierto suma 10 puntos y hay 3 pistas que restan 5.
- **Explorar sin jugar:** tocas cualquier estación para ver su ficha con definición, características, usos y un ejemplo.

## Accesibilidad

- Tres temas de color: oscuro, claro y alto contraste.
- Manejo completo con teclado.
- Vista de lista como alternativa al mapa.
- Las líneas se distinguen por el trazo y no solo por el color.
- No usa audio ni video, por lo que no requiere subtítulos.

## Tecnología

Un solo archivo HTML con CSS y JavaScript propios, sin librerías externas. Las ilustraciones son vectoriales y de elaboración propia.
